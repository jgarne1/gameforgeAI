# World Forger Real Assets Starter

This package replaces the failed AI concept-style terrain sheet with a real, exact-grid game asset sheet.

## Where to store the PNG

public/assets/worldkit/whisperwind/terrain_foundation_01.png

## Where to store the catalog

data/world_asset_catalog.json

## Where alignment tuning saves

data/world_asset_alignment.json

## Rules

- 128 x 128 cells
- 8 columns x 8 rows
- transparent PNG
- no labels
- no UI
- no poster background
- catalog references each cell by ID
- these are starter production assets, not final hand-painted art

## Important

This is intentionally clean and sliceable. It may be less beautiful than concept art, but it is usable by the engine and editor.
