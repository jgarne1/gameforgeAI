Shadow Woods scene connection notes - first pass

Coordinate rule:
- All coordinates are local to each scene image, measured from the top-left corner.
- Entry/spawn points should place the player just inside the new scene, facing toward the area they are entering.
- Exit hotspots should sit slightly inside the visible path/door/cave mouth, not outside the playable boundary.

Current connections:
1) shadow_woods_dock -> shadow_woods_river_bend
   - Exit hotspot: deeper_woods_exit / North trail to River Bend
   - Target scene: shadow_woods_river_bend
   - Target spawn: from_fishing_dock
   - Reasoning: the player leaves the existing dock scene by heading north/up the trail, so they enter River Bend from the bottom/south edge and face up.

2) shadow_woods_river_bend -> shadow_woods_dock
   - Exit hotspot: south_return_exit / South trail back to Fishing Dock
   - Target scene: shadow_woods_dock
   - Target spawn: from_river_bend
   - Reasoning: returning south from River Bend places the player near the north trail entrance in the dock scene, facing down.

Editor workflow:
- Open games/world_editor.html.
- Select a scene from the dropdown.
- Use Add exit to place or adjust exits.
- Use Add entry/spawn point to create named arrival points.
- For an exit, set Target Scene and Target Spawn ID.
- Use Save browser draft for quick testing, or Download JSON for a drop-in scene file.
