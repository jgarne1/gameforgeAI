# Nature details v1

Three reusable alpha originals: low meadow flower crescent, berry/blossom shrub and fern/cattail clump. Metadata records dimensions, SHA256, measured source bounds and bottom-center placement. Use varied groups beside paths and on banks; keep walking corridors, stairs, door approaches and sightlines clear. Flowers and reeds need no collision. A large shrub may use a small root footprint. Sources are unchanged; color variation requires a separately generated source.
